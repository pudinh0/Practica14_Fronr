¿por qué en la pestaña Red salen dos peticiones al cargar?
por el strictmode, cuando se ejcuta en modo dev, el framework de react construye y desarma los componentes para detectar algunos errores.

¿qué pasa si quitas el arreglo de dependencias del efecto? 
se ejectaria cada vez que se actualizara un estado

¿qué hace e.preventDefault() y qué pasa si lo quitas?
sirve para detener la acción por defecto que el navegador ejecuta ante un determinado evento
